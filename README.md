# CC: Rewired
> ComputerCraft, rewired for modern Minecraft.

> [!WARNING!] CC: Rewired is in early pre-alpha development. There are no official releases yet, and the current codebase still behaves primarily as CC: Tweaked.

CC: Rewired, officially CC:RW, is a community-driven fork of CC: Tweaked, itself a fork of the original ComputerCraft. It aims to rethink ComputerCraft for modern Minecraft while retaining Lua programming and as much useful ecosystem compatibility as reasonably possible.
The long-term goal is a redesign of the computers, user experience, operating system, peripherals, power requirements and networking model around technology recognisable from the 2020s — reinterpreted through Minecraft visual palette.
