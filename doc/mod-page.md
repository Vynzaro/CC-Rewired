# CC: Rewired

**ComputerCraft, rewired for modern Minecraft.**

CC: Rewired (CC:RW) is an independent fork of [CC: Tweaked], itself based on the original [ComputerCraft]. It preserves
programmable computers, turtles, Lua APIs and the existing addon ecosystem while rebuilding the mod's presentation and
user experience for modern Minecraft.

> **Early alpha:** the current release line establishes the project's identity and visual foundation. Networking,
> electricity, modern cables and other large systems described in the roadmap are not released features yet.

## Current compatibility

- Minecraft 1.20.1
- Forge 47 as the primary supported loader
- Client and server
- Existing `computercraft` IDs and Lua APIs retained

Because CC: Rewired deliberately retains the `computercraft` mod ID for compatibility, **do not install it together with
CC: Tweaked**.

## Included foundation

- Lua-programmable computers and pocket computers.
- Mining and automation turtles.
- Monitors, printers, speakers, disk drives and modems.
- Peripheral integration with inventories and compatible modded blocks.
- HTTP, WebSocket, filesystem, shell and networking APIs.

These systems originate in ComputerCraft and CC: Tweaked. CC: Rewired will change them incrementally, with migrations and
compatibility effects documented per release.
