This is the API documentation for CC: Rewired $modVersion on Minecraft $mcVersion. CC: Rewired retains the established dan200.computercraft.api packages so existing CC: Tweaked addons can remain compatible.

Quick links

Start with the following APIs:

  • {@linkplain dan200.computercraft.api.peripheral Registering new peripherals}
  • {@link dan200.computercraft.api.lua.LuaFunction} and {@link dan200.computercraft.api.lua.IArguments} for adding methods to peripherals or Lua objects.
  • {@linkplain dan200.computercraft.api.turtle.ITurtleUpgrade Turtle upgrades}
  • {@linkplain dan200.computercraft.api.pocket.IPocketUpgrade Pocket upgrades}

Using development artifacts

CC: Rewired does not currently operate a public Maven repository. Run publishToMavenLocal in a local checkout, and then depend on the required API artifact from mavenLocal(): 

repositories {
    mavenLocal()
}

dependencies {
    // Common API for multi-loader projects.
    compileOnly("io.github.vynzaro:cc-rewired-$mcVersion-common-api:$modVersion")

    // Forge API and development runtime.
    compileOnly("io.github.vynzaro:cc-rewired-$mcVersion-core-api:$modVersion")
    compileOnly(fg.deobf("io.github.vynzaro:cc-rewired-$mcVersion-forge-api:$modVersion"))
    runtimeOnly(fg.deobf("io.github.vynzaro:cc-rewired-$mcVersion-forge:$modVersion"))
}

Only use classes inside dan200.computercraft.api. Other inherited implementation packages are not public API and may change without notice. Propose missing integration hooks in the CC: Rewired issue tracker.
