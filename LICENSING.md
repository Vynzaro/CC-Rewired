# Licensing CC: Rewired

CC: Rewired is a fork of CC: Tweaked and contains inherited source code, assets and third-party components. It is not
distributed under one blanket license. The applicable license and copyright holder are recorded for each file using
SPDX metadata.

The authoritative licensing information is, in order:

1. The SPDX header inside a file.
2. A neighbouring `.license` file for binary or otherwise non-commentable files.
3. The matching annotation in [`REUSE.toml`](REUSE.toml).

Full license texts are stored in [`LICENSES/`](LICENSES/). Much of the mod's distributable ComputerCraft-derived code
and assets is covered by the ComputerCraft Public License 1.0 (`LicenseRef-CCPL`), while much of the supporting source
and build infrastructure is covered by the Mozilla Public License 2.0. Bundled or adapted third-party components retain
their own licenses and notices.

Copyright notices belonging to ComputerCraft, CC: Tweaked and third-party contributors remain in place. New CC: Rewired
work identifies its own copyright holder without replacing those inherited notices.
